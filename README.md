# Western Victoria Health Services Telehealth Network

## Project Overview
This project simulates a regional healthcare telehealth network for Western Victoria Health Services (WVHS) using Cisco Packet Tracer.

The network connects:
- Ballarat Central Diagnostic Hub
- Ararat Medical Clinic
- Horsham Medical Clinic

The infrastructure supports:
- Telehealth consultations
- Medical imaging transfer
- Electronic Health Records (EHR)
- Administrative systems

---

## Technologies Used
- Cisco Packet Tracer
- Cisco 2911 & 1941 Routers
- Cisco 2960 Switches
- EIGRP Dynamic Routing
- VLSM Subnetting
- ACL Firewall Configuration
- WAN Serial Connections
